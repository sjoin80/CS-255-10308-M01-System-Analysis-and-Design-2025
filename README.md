# CS-255-10308-M01-System-Analysis-and-Design-2025

CS-255-10308-M01 System Analysis and Design 2025

The DriverPass project focused on creating a web-based system to help students prepare for driving exams through online courses and in-person lessons. The client wanted an efficient way to manage student accounts, schedule driving sessions, and track progress. My task was to gather requirements and design a complete system that met those goals using UML diagrams and structured documentation.

I did especially well in organizing the system requirements and connecting each use case to a specific client need. My diagrams clearly showed how users interact with the system and how data flows between roles like students, instructors, and administrators.

If I could improve one area, I would refine the nonfunctional requirements with more measurable performance metrics, such as response time or load capacity.

I interpreted the user’s needs by reviewing the interview transcript and focusing on convenience, scheduling accuracy, and system security. Meeting user needs is essential because a design only succeeds if it improves the user’s experience.

My design approach is structured and iterative, beginning with modeling and ending with refinement based on feedback. In future projects, I plan to use more prototyping and version control to improve collaboration and trace design decisions.
